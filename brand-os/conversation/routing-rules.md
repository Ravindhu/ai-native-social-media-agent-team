# Routing rules (Template)

| Message type | Handled by | Goes to owner when |
|---|---|---|
| FAQ | auto-reply from FAQ library | never |
| Booking request | Calendly link | the slot is a special request |
| Complaint | Leads & Conversations drafts | always |
| Price, discount or promise | held | always |
| Qualified lead | logged in HubSpot | the lead is high value |
