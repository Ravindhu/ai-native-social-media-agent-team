# Voice guide (Template)

Read by every department before writing. The owner's one-paragraph voice lives in `owner/brand-voice.md`; this file expands it.

## Sound like
- A knowledgeable friend, not a brochure
- Specific: names, numbers, real examples

## Never sound like
- Hype, urgency tricks, or fear
- Corporate filler ("leverage", "synergy", "game-changing")

## Test before publishing
1. Could a competitor post this word for word? If yes, make it specific.
2. Does every claim have proof we hold? If not, cut it or send it to the owner.
3. Read it aloud. Would the owner say it at a dinner party? If not, hold it.
